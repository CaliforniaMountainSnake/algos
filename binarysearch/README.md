# Binary Search

Алгоритмы поиска в отсортированном пространстве.

Включает:

- классический бинарный поиск;
- поиск первого/последнего вхождения;
- lower bound / upper bound;
- поиск границы;
- поиск точки перехода;
- бинарный поиск по ответу;
- поиск в rotated sorted array;
- задачи на монотонные функции.

Основная идея: если пространство решений монотонно, его часто можно уменьшать вдвое на каждом шаге.
