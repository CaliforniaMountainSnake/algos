# Dynamic Programming

Задачи с перекрывающимися подзадачами и оптимальной подструктурой.

Включает:

- memoization;
- tabulation;
- 1D DP;
- 2D DP;
- DP по последовательностям;
- DP по строкам;
- knapsack;
- subsequences;
- coin change;
- interval DP;
- tree DP;
- state compression;
- переход от рекурсии к DP.

Основная идея: определить состояние задачи, переход между состояниями и базовые случаи, сохраняя уже вычисленные результаты.
