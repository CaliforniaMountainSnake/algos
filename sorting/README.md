# Sorting

Алгоритмы упорядочивания данных и задачи, где сортировка упрощает дальнейшее решение.

Включает:

- bubble sort;
- selection sort;
- insertion sort;
- merge sort;
- quicksort;
- counting sort;
- radix sort;
- сортировку объектов по ключу;
- сортировку перед применением других алгоритмов;
- анализ сложности сортировок.

Основная идея: иногда выгоднее сначала потратить время на сортировку, чтобы затем решить задачу значительно проще.
