# Heaps

Задачи, где необходимо быстро получать минимальный или максимальный элемент.

Включает:

- min heap;
- max heap;
- priority queue;
- вставку и удаление элементов;
- top K problems;
- поиск K-го максимального/минимального элемента;
- слияние отсортированных последовательностей;
- поддержание набора лучших кандидатов.

Основная идея: поддерживать множество элементов так, чтобы экстремальный элемент был доступен за O(1), а изменение структуры — за O(log n).
