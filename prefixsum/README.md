# Prefix Sum

Предварительное накопление информации для быстрых запросов по диапазонам.

Включает:

- prefix sum;
- range sum queries;
- difference array;
- двумерные prefix sums;
- подсчёт количества элементов на диапазоне;
- преобразование запросов по диапазонам;
- связь с hash map для поиска подмассивов с заданной суммой.

Основная идея: один раз вычислить накопленную информацию, чтобы потом отвечать на запросы за O(1) или близко к этому.
