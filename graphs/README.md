# Graphs

Задачи на отношения и связи между объектами.

Включает:

- представление графов;
- adjacency list / matrix;
- DFS;
- BFS;
- поиск компонент связности;
- поиск циклов;
- топологическую сортировку;
- shortest path;
- Dijkstra;
- Bellman-Ford;
- Floyd-Warshall;
- minimum spanning tree;
- Union-Find / DSU;
- ориентированные и неориентированные графы;
- взвешенные и невзвешенные графы.

Основная идея: рассматривать задачу как множество состояний и переходов между ними.
