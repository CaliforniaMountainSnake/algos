# Sliding Window

Задачи на непрерывные подмассивы или подстроки.

Включает:

- фиксированное окно;
- окно переменного размера;
- поиск максимума/минимума в окне;
- подсчёт частот внутри окна;
- поиск самой длинной/короткой подходящей последовательности;
- поддержание условий при движении окна.

Основная идея: вместо пересчёта каждого подмассива поддерживать состояние текущего окна и двигать его границы.
