Практика алгоритмов и структур данных для подготовки к алгоритмическим собеседованиям.

Основная цель — не запомнить решения сотен задач, а научиться распознавать **паттерны решения**, выбирать подходящую структуру данных и оценивать сложность алгоритма.

## Topics

| Раздел                                       | Что здесь                                                                            |
| -------------------------------------------- | ------------------------------------------------------------------------------------ |
| [Arrays](./arrays/)                          | Массивы, матрицы, подмассивы и базовые операции над последовательностями.            |
| [Strings](./strings/)                        | Обработка строк, символов, подстрок и строковых паттернов.                           |
| [Hash](./hash/)                              | HashMap/HashSet, частоты, быстрый поиск и связывание данных.                         |
| [Linked List](./linkedlist/)                 | Связные списки, указатели, разворот, циклы и операции с узлами.                      |
| [Stack](./stack/)                            | LIFO, вложенные структуры, monotonic stack и задачи на ближайшие элементы.           |
| [Queue](./queue/)                            | FIFO, deque и задачи, где элементы обрабатываются по порядку.                        |
| [Sorting](./sorting/)                        | Сортировки и задачи, где сортировка является частью решения.                         |
| [Binary Search](./binarysearch/)             | Поиск в отсортированных данных, границы и binary search on answer.                   |
| [Two Pointers](./twopointers/)               | Два указателя для поиска пар, диапазонов и эффективного обхода.                      |
| [Sliding Window](./slidingwindow/)           | Работа с непрерывными подмассивами и подстроками через движущееся окно.              |
| [Prefix Sum](./prefixsum/)                   | Предварительные вычисления для быстрых запросов по диапазонам.                       |
| [Recursion](./recursion/)                    | Рекурсия, рекурсивный обход и divide & conquer.                                      |
| [Backtracking](./backtracking/)              | Перебор вариантов с откатом и отсечением невозможных ветвей.                         |
| [Trees](./trees/)                            | Деревья, BST, обходы, рекурсивные и итеративные решения.                             |
| [Heaps](./heaps/)                            | Heap, priority queue, top-K и поддержание минимума/максимума.                        |
| [Graphs](./graphs/)                          | BFS, DFS, пути, компоненты, топологическая сортировка и другие графовые алгоритмы.   |
| [Greedy](./greedy/)                          | Локально оптимальные решения, интервалы, расписания и доказательство greedy-подхода. |
| [Dynamic Programming](./dynamicprogramming/) | Состояния, переходы, memoization, tabulation и оптимизация подзадач.                 |
| [Bitwise](./bitwise/)                        | Битовые операции, маски, XOR и представление множеств битами.                        |
| [Math](./math/)                              | Теория чисел, комбинаторика, геометрия и математические закономерности.              |
