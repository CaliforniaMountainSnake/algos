# Stack

Задачи, основанные на принципе LIFO — последний вошёл, первый вышел.

Включает:

- реализацию стека;
- проверку скобок;
- обработку вложенных конструкций;
- монотонный стек;
- поиск ближайшего большего/меньшего элемента;
- вычисление выражений;
- симуляцию операций с историей состояний.

Основная идея: когда важно помнить только последние незавершённые или добавленные элементы.
