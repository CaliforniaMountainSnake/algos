# Math

Математические алгоритмы и задачи, которые не сводятся преимущественно к одной структуре данных.

Включает:

- делимость;
- простые числа;
- GCD / LCM;
- алгоритм Евклида;
- факторизацию;
- степени и логарифмы;
- комбинаторику;
- перестановки и сочетания;
- модульную арифметику;
- матрицы;
- геометрию;
- вероятности;
- числовые последовательности;
- математические закономерности.

Основная идея: распознать математическую структуру задачи и использовать её вместо грубой силы.
