# Backtracking

Систематический перебор пространства вариантов с возвратом после неудачного выбора.

Включает:

- генерацию подмножеств;
- генерацию перестановок;
- комбинации;
- размещения;
- задачи с ограничениями;
- N-Queens;
- Sudoku;
- поиск путей;
- pruning — отсечение заведомо бесполезных ветвей.

Основная идея: строить решение пошагово, откатывая последний выбор, когда продолжение больше не имеет смысла.
