# Greedy

Задачи, где решение строится последовательностью локально оптимальных выборов.

Включает:

- выбор максимального/минимального кандидата на каждом шаге;
- interval scheduling;
- задачи на интервалы;
- распределение ресурсов;
- минимизацию/максимизацию;
- сортировку + greedy;
- доказательство корректности жадного выбора;
- exchange argument.

Основная идея: сделать лучший доступный выбор сейчас и доказать, что такой выбор не испортит глобальный оптимум.
