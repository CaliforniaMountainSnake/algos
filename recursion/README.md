# Recursion

Задачи, где решение определяется через решение меньших экземпляров той же задачи.

Включает:

- базовые рекурсивные функции;
- рекурсивный обход структур данных;
- divide and conquer;
- рекурсивную обработку деревьев;
- рекурсивное разбиение задачи;
- анализ глубины рекурсии;
- связь рекурсии со стеком вызовов.

Основная идея: представить большую задачу как комбинацию меньших задач того же типа.
