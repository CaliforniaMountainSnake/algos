# Strings

Алгоритмы обработки строк и последовательностей символов.

Включает:

- обход строк;
- сравнение и преобразование строк;
- подсчёт символов;
- проверку палиндромов;
- поиск подстрок;
- построение и разбор строк;
- работу с частотами символов;
- анаграммы;
- базовые алгоритмы поиска шаблонов.

Основная идея: строка часто является массивом символов, но имеет собственные паттерны и ограничения.
