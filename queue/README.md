# Queue

Задачи, основанные на принципе FIFO — первый вошёл, первый вышел.

Включает:

- обычную очередь;
- deque;
- круговые очереди;
- BFS;
- обработку элементов по порядку поступления;
- симуляцию процессов и событий;
- очереди с приоритетом как переход к heap.

Основная идея: обрабатывать данные в порядке их поступления.
