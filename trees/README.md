# Trees

Алгоритмы работы с иерархическими структурами.

Включает:

- binary tree;
- binary search tree;
- DFS;
- BFS;
- preorder / inorder / postorder;
- поиск глубины и высоты;
- поиск предков;
- сравнение деревьев;
- построение деревьев;
- балансировку;
- trie;
- рекурсивные и итеративные обходы.

Основная идея: использовать иерархическую структуру данных для разбиения задачи на поддеревья.
