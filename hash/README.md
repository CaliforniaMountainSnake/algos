# Hash

Задачи, где хеш-таблица позволяет быстро хранить, находить и связывать данные.

Включает:

- hash map / hash set;
- подсчёт частот;
- поиск дубликатов;
- проверку существования элементов;
- группировку элементов;
- отображение одного значения в другое;
- поиск пар и комбинаций;
- запоминание уже обработанных данных.

Основная идея: заменить дорогостоящий поиск по структуре данных на быстрый доступ по ключу.
