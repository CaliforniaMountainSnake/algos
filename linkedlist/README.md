# Linked List

Алгоритмы работы со связными списками.

Включает:

- односвязные и двусвязные списки;
- вставку и удаление узлов;
- разворот списка;
- поиск середины;
- обнаружение циклов;
- слияние списков;
- fast/slow pointers;
- удаление узлов с определённым смещением;
- перестановку элементов списка.

Основная идея: работать со структурой, где элементы связаны ссылками, а не расположены непрерывно в памяти.
