# Arrays

Базовые задачи на работу с последовательностями элементов.

Включает:

- обход и изменение массивов;
- поиск элементов и свойств последовательности;
- разворот, сдвиг, перестановки;
- удаление и вставку элементов;
- in-place алгоритмы;
- подсчёт частот и агрегирование;
- работа с подмассивами;
- поиск максимума/минимума;
- одномерные и двумерные массивы;
- матрицы и их обход.

Основная идея: научиться эффективно работать с последовательностью данных, не создавая лишнюю память.
