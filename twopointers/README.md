# Two Pointers

Задачи, где два индекса перемещаются по одной или нескольким последовательностям.

Включает:

- движение указателей навстречу друг другу;
- движение в одном направлении;
- поиск пар;
- удаление дубликатов;
- работу с отсортированными массивами;
- задачи на палиндромы;
- fast/slow pointers;
- слияние последовательностей.

Основная идея: использовать взаимосвязь между позициями элементов, чтобы избежать полного перебора всех пар.
