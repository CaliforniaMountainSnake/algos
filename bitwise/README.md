# Bitwise

Алгоритмы, использующие представление чисел в виде битов.

Включает:

- AND, OR, XOR, NOT;
- bit shifts;
- проверку и установку битов;
- маски;
- подсчёт установленных битов;
- XOR tricks;
- bitmask;
- представление множества битовой маской;
- задачи на степени двойки;
- оптимизации через битовые операции.

Основная идея: рассматривать число не как значение, а как набор отдельных битов и работать непосредственно с ними.
